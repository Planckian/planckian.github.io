ArchBuilder

A quantum architecture design suite for superconducting quantum devices. ArchBuilder is an integrated, GUI-driven workspace for circuit design, Hamiltonian analysis, pulse engineering and quantum simulation — from schematic to optimised pulse, all in one environment.

ArchBuilder is in alpha and has not had a public release yet. The rendered API documentation is already online, and every release ships the same documentation alongside the application so it works offline.

API documentation → Zhivago documentation GitHub ↗

The pipeline

One project file, five stages

The tools are not separate applications that happen to sit in the same folder. A shared project hub and an event bus carry the circuit, the layout and the Hamiltonian between them, so a change upstream shows up downstream.

01

Design

Draw the superconducting circuit in Steppenwolf; QuCAT turns it into a Hamiltonian.

02

Analyse

Edit that Hamiltonian symbolically in Livingston — RWA, frame changes, term algebra.

03

Wire

Connect degrees of freedom and layouts across the tools on the Morpheus canvas.

04

Pulse

Compose drives in Bovary, then optimise them with Frankenstein and AIgor.

05

Simulate

Time-evolve in Metamorphosis via QuTiP, or hand large systems to Zhivago.

The tools

Nine tools in one workspace

ToolWhat it does
ArchBuilderProject manager and central hub — loads and saves projects, wires tools together
SteppenwolfSuperconducting circuit design via QuCAT; generates Hamiltonians and exports JSON specs
LivingstonSymbolic Hamiltonian editor; RWA, frame transformations, graph-based term algebra
Morpheus / LinesWiring canvas — connects degrees of freedom and layouts across tools
BovaryPulse composer; builds and previews drive pulses
MetamorphosisQuantum dynamics simulator; integrates with QuTiP for time evolution
FrankensteinGate-level optimizer; connects to AIgor for GRAPE and CRAB pulse optimisation
AIgorStandalone pulse optimizer using qutip-qtrl — GRAPE, CRAB, basin-hopping
ZhivagoJulia tensor-network simulation backend, ITensor-based, optional

New GUI apps and plugins are discovered at startup, so the suite can be extended without touching the shell. Full class and function reference: ArchBuilder API documentation →

Running it

Requirements and install

Python 3.11+

With conda (Anaconda or Miniconda) strongly recommended for environment management.

Julia 1.11+

Only needed for the Zhivago tensor-network simulation backend. Everything else runs without it.

Windows · macOS · Linux

One-shot bootstrap script per platform. Linux also needs python3-tk.

Interactive installer

The wizard creates the conda environment, installs core and optional packages, sets up the Julia bridge and registers your licence.

python Installation/install.py

conda activate Planckian
python ArchBuilderShell.py

The installer can also run non-interactively for CI, with --create-env, --core, --optional, --julia, --docs and --register.

Zhivago on its own

The simulation backend is self-contained and can be installed without ArchBuilder — the setup script offers it as a separate option. Its documentation is here.
