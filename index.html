Superconducting quantum processors

A whole lot of qubits.
A handful of wires.

Every superconducting qubit normally wants its own control lines, and that — not coherence — is what stops the technology scaling. Planckian drives the whole register with a few shared fields instead, and engineers the couplings so that a global pulse still does something different to each qubit.

The approach

If every qubit hears the same pulse,
what makes them behave differently?

There are two good answers, and they are opposites. Planckian works on both.

Switchable XY · iSWAP

Move the qubit to the control

Keep only two global couplings and one addressable site. Alternating layers of exchange gates transport any qubit to that site, so locality of control is traded for depth of routing — and the wire count never grows with the register.

Always-on ZZ · blockade

Let the neighbours decide

Do not switch anything off. Make the parasitic ZZ interaction the largest energy in the problem, and an excited qubit shifts its neighbour clean out of resonance — so a shared pulse moves only the qubits whose surroundings permit it.

Upcoming v0.5 alpha

ArchBuilder — schematic to optimised pulse,
in one environment

Designing a globally controlled processor means moving constantly between circuit layout, Hamiltonian, pulse and simulation. ArchBuilder is the GUI-driven suite we built to stop that being nine separate tools with nine file formats. It is in alpha and not yet publicly released — the API documentation is already online.

ToolWhat it does
ArchBuilderProject manager and central hub — loads and saves projects, wires the tools together
SteppenwolfSuperconducting circuit design via QuCAT; generates Hamiltonians and exports JSON specs
LivingstonSymbolic Hamiltonian editor; RWA, frame transformations, graph-based term algebra
MorpheusWiring canvas — connects degrees of freedom and layouts across tools
BovaryPulse composer; builds and previews drive pulses
MetamorphosisQuantum dynamics simulator; integrates with QuTiP for time evolution
FrankensteinGate-level optimizer; connects to AIgor for GRAPE and CRAB pulse optimisation
AIgorStandalone pulse optimizer using qutip-qtrl — GRAPE, CRAB, basin-hopping
